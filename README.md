Overview

This project develops a deep learning model to classify Malaysian ethnicities (Malay, Chinese, Indian) using facial images. The model uses transfer learning with the VGG-Face architecture to achieve accurate predictions while minimizing training time.

Features

- Classifies images into Malay, Chinese, or Indian ethnicities
- Uses transfer learning for efficient and accurate deep learning
- Includes data preprocessing: resizing, normalization, and augmentation
- Model trained with TensorFlow/Keras for easy experimentation and reproducibility

Technologies Used

- Python
- TensorFlow / Keras
- VGG-Face (pre-trained model)
- NumPy, Pandas, OpenCV (for image processing)
